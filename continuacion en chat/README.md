# Continuación en chat

Esta carpeta existe para NO tener que subir el ZIP completo de Abraxas OS
en cada conversación.

## Qué subir normalmente al chat

Primero sube solamente:

`ABRAXAS_OS_CONTINUACION_CHAT.md`

Ese archivo contiene:

- de dónde viene el proyecto;
- dónde está ahora;
- arquitectura vigente;
- módulos;
- último check;
- errores actuales;
- siguiente paso;
- Git status;
- versiones importantes.

## Cuándo sí hace falta subir más

Sólo cuando:

- hay un error que no queda descrito en el archivo de continuación;
- hay que inspeccionar código concreto;
- hay diferencias entre el estado reportado y el repositorio;
- se necesita revisar un asset/binario;
- se solicita una auditoría completa.

Los archivos de esta carpeta son generados.
La fuente de verdad sigue estando en PROJECT_CONTROL y en el código.
