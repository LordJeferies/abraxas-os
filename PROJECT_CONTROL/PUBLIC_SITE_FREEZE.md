# Public Site Freeze

El sitio público queda en mantenimiento mientras se certifica F1 y se construye
F2.

El sitio es comunicación del producto, no el producto.

No añadir nuevas iteraciones visuales antes de F1/F2 salvo:

- sitio caído;
- contenido incorrecto;
- problema grave de performance;
- seguridad/privacidad.

Cuando se retome, evaluar Shopify Editions Spring 2026 como referencia
feature-first.
