# Ficha Studio

Cada Potencial Alfa abre una Ficha Studio editable antes de entrar al Editor.

La Ficha Studio:
- muestra título, tesis, objetivo, copy, status y notas;
- organiza recursos en mini-kanban Narrativa / Visual / Audio;
- permite editar label, descripción, texto y prompt por recurso;
- muestra la Timeline T1-T9 canónica;
- abre VideoFlow cuando corresponde.

Las ediciones NO mutan el HTML importado ni `sourcePayload`.
Se guardan como `abraxas.alpha-content-edit.v1` en IndexedDB.
