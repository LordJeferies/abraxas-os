# CLIENTES PRIVADOS — SÓLO LOCAL

Esta carpeta está diseñada para uso real de Abraxas OS con clientes.

NO debe publicarse en el repositorio GitHub público.

Aquí pueden vivir:

- videos privados;
- podcasts de clientes;
- masters;
- audio real;
- transcripciones privadas;
- documentos del cliente;
- assets confidenciales;
- material sin publicar;
- archivos de trabajo;
- exports;
- logs que incluyan nombres o rutas de material privado.

## Organización sugerida

La aplicación irá creando proyectos con una estructura compacta.

Ejemplo conceptual:

proyectos/
└── cliente/
    └── proyecto/
        ├── project.json
        ├── source/
        ├── editorial/
        ├── assets/
        └── output/

No crear manualmente decenas de carpetas por pieza.
Abraxas OS administrará esta estructura cuando llegue Asset Workflow / Project Manager.
