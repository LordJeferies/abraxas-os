# Abraxas OS

Content Operating System para producción editorial y audiovisual.

## Estado

Foundation v0.1

La primera implementación real se centra en:

1. reproductor real,
2. timeline de producción,
3. objetos fantasma,
4. inspector contextual,
5. adaptación Alfa -> Production Graph -> VideoFlow,
6. posterior integración nativa macOS.

## Regla fundamental

Abraxas OS es la fuente de verdad editorial.

VideoFlow es un motor de edición/preview/render conectado mediante un adapter.

Tauri es el shell desktop.

Apple Media será el motor nativo principal para operaciones macOS donde aporte
velocidad, precisión o calidad.
